# FlatMate
FlatMate — это платформа для студентов и молодых людей, которая помогает находить совместимых соседей для совместного проживания.

О проекте:
FlatMate помогает пользователям находить соседей не только по бюджету и расположению жилья, но и по образу жизни, привычкам и личным предпочтениям. Пользователи могут создать профиль, указать свои интересы и предпочтения, оценить совместимость, добавлять понравившиеся профили в избранное и читать отзывы.
